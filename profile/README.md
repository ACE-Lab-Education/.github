<h1 align="center">ACE-Lab</h1>
<p align="center"><b>Practical First. Theory Follows.</b><br>Affordable, portable control-engineering hardware, programmed with MATLAB &amp; Simulink.</p>

<p align="center"><img src="https://custom-images.strikinglycdn.com/res/hrscywv4p/image/upload/f_auto,q_auto/22329992/543744_727789.png" alt="ACE-Lab Base + Sense" height="190">&nbsp;&nbsp;&nbsp;<img src="https://custom-images.strikinglycdn.com/res/hrscywv4p/image/upload/f_auto,q_auto/22329992/895721_522242.png" alt="ACE-Lab Actuate" height="190"></p>

ACE-Lab helps students, educators and researchers learn control engineering by **doing it on real hardware first**, then connecting what they see to the theory.
